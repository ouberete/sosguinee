error_outline {% trans "1. Alertes de perte & Retrouvailles" %}

  • help {% trans "Comment signaler une alerte de perte de bien ou de proche ?" %} expand_more

    {% trans "Pour publier un signalement :" %}

    1. {% blocktrans %}Rendez-vous sur la page Signaler une alerte.{% endblocktrans %}
    2. {% trans "Renseignez le nom, la description précise, le lieu exact et la date de la disparition." %}
    3. {% trans "Ajoutez une photo claire (fortement recommandé pour augmenter les chances de reconnaissance)." %}
    4. {% trans "Soumettez le formulaire. Votre alerte sera instantanément visible sur la plateforme et partageable sur les réseaux sociaux." %}
  • help {% trans "Comment signaler un bien ou un proche que j'ai retrouvé ?" %} expand_more

    {% blocktrans %}Si vous avez retrouvé un objet ou recueilli une personne égarée, vous pouvez également publier une alerte en sélectionnant la catégorie appropriée (Trouvaille) via le formulaire de signalement. Décrivez l'objet sans révéler tous les détails confidentiels (ex. : gardez un élément d'identification pour vérifier le propriétaire légitime).{% endblocktrans %}

  • help {% trans "Comment suivre et clôturer mon alerte une fois résolue ?" %} expand_more

    {% blocktrans %}Connectez-vous à votre compte, accédez à la page de votre alerte ou à votre profil. Dès que la personne ou le bien est retrouvé, cliquez sur « Marquer comme résolu / Clôturer » afin d'informer la communauté et d'éviter que des recherches inutiles ne continuent.{% endblocktrans %}

monetization_on {% trans "2. Demandes de financement solidaire" %}

  • help {% trans "Comment ajouter une demande de financement ?" %} expand_more
    1. {% blocktrans %}Connectez-vous à votre compte et cliquez sur Ajouter une demande de financement.{% endblocktrans %}
    2. {% trans "Indiquez le titre, le nom du bénéficiaire, le montant objectif en Francs Guinéens (GNF), la catégorie et la date d'échéance." %}
    3. {% trans "Téléversez une image principale ainsi que les justificatifs nécessaires (pièce d'identité et certificat médical ou attestation)." %}
    4. {% trans "Validez votre soumission. Notre équipe examine les pièces pour assurer la crédibilité avant validation finale." %}
  • help {% trans "Pourquoi une vérification des pièces justificatives est-elle exigée ?" %} expand_more

    {% blocktrans %}Pour protéger la générosité des donateurs et éviter les tentatives d'usurpation d'identité ou d'escroquerie, chaque demande solidaire fait l'objet d'un contrôle antifraude (pièce d'identité valide, dossier médical/communautaire). Cela garantit un taux de confiance maximal pour les donateurs.{% endblocktrans %}

  • help {% trans "Que signifie le statut « Entièrement financé » ou « Collecté » ?" %} expand_more

    {% blocktrans %}Lorsqu'une demande atteint 100% de son objectif financier, elle affiche le statut « Collecté » ou « Entièrement financé ». Selon la nature de la demande, la collecte peut être clôturée ou prolongée pour couvrir d'éventuels frais annexes imprévus (convalescence, médicaments).{% endblocktrans %}

payment {% trans "3. Dons & Moyens de paiement sécurisés" %}

  • help {% trans "Quels sont les moyens de paiement acceptés ?" %} expand_more

    {% trans "En partenariat avec la passerelle certifiée Djomy Africa, nous acceptons :" %}

    • {% trans "Orange Money Guinée" %} ({% trans "via validation par code OTP sur votre téléphone" %})
    • {% trans "MTN Mobile Money Guinée" %}
    • {% trans "Cartes bancaires (Visa, Mastercard)" %} {% trans "pour les donateurs résidant en Guinée et à l'étranger (diaspora)." %}
  • help {% trans "Comment fonctionnent les frais de transaction Djomy ?" %} expand_more

    {% blocktrans %}Le prestataire agréé Djomy applique les frais d'acheminement standards des opérateurs télécoms (Orange, MTN) ou bancaires selon le moyen choisi. Le montant débité par l'opérateur inclut ces frais techniques réels. Ensemble 224 ne prélève aucun frais caché sur votre don.{% endblocktrans %}

  • help {% trans "Mes coordonnées bancaires ou Mobile Money sont-elles protégées ?" %} expand_more

    {% blocktrans %}Oui, à 100%. Ensemble 224 ne reçoit ni ne stocke jamais votre code secret PIN Mobile Money ou vos identifiants bancaires. Toutes les saisies de sécurité sont directement effectuées sur l'interface sécurisée et chiffrée de votre opérateur téléphonique.{% endblocktrans %}

gavel {% trans "4. Sécurité, Restitution & Arbitrage" %}

  • help {% trans "Pourquoi l'arbitrage légal ou l'intervention des autorités est-il mentionné ?" %} expand_more

    {% blocktrans %}Pour les cas particulièrement sensibles (enfants ou proches vulnérables retrouvés, biens matériels de très forte valeur, ou litige entre personnes), la remise doit s'effectuer en présence ou sous le constat des autorités compétentes (services de sécurité, police/gendarmerie ou autorité administrative). Cela protège à la fois la personne qui a trouvé le bien et le propriétaire légitime.{% endblocktrans %}

  • help {% trans "Comment signaler un abus ou une alerte frauduleuse ?" %} expand_more

    {% blocktrans %}Si vous constatez une alerte suspecte ou des commentaires inappropriés, contactez immédiatement l'équipe par email à contact@ensemble224.org ou via notre page de contact. Nous suspendons immédiatement tout contenu faisant l'objet d'un doute sérieux.{% endblocktrans %}
